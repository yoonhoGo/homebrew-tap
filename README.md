# homebrew-tap

Homebrew tap for [keyouse](https://github.com/yoonhoGo/keyouse).

```bash
brew install yoonhoGo/tap/keyouse
```

## Ukemi

Desktop GUI for Jujutsu. The source repository is private; this tap carries
the public Cask and release DMG for Apple silicon.

```bash
brew install --cask yoonhoGo/tap/ukemi
```
